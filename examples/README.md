# HuProt HEPACAM and viral proteins

Target: HuProt 4.0 HEPACAM (JHU19101; Q14CZ8), 416 amino acids. The viral-m5 and viral-m7 folders compare it with Curated Viral Proteomes (120). The ebv-m5 folder contains the Epstein-Barr virus B95-8 subset at 5/9. Each folder includes the supplied complete matches, parent table, site-376 table, summary and figure ZIP. Original data and figure files are unchanged. These are sequence-comparison results, not antibody measurements.

The website shows pan-viral coverage plots at 5/9 and 7/9, and EBV site-376 alignments at 5/9. The separately highlighted published alignment is HEPACAM 376-384 versus EBNA1 392-400. Site rankings use the exported Context BLOSUM62 values.
