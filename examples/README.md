# Worked-example downloads

These saved results and figures accompany the three walkthroughs in the main README.

- [HEPACAM: combine with experimental evidence](hepacam-huprot-viral-example.zip) — HuProt HEPACAM versus 120 viral proteomes, with an EBV site comparison; 21.5 MB.
- [IL10: compare across proteomes](il10-example.zip) — 120 viral proteomes at 5/9 and 7/9; 5.0 MB.
- [IGHG2: find uniqueness within proteomes](ighg2-example.zip) — human-proteome comparison at 8/9; 7.0 MB.

Each ZIP includes CSV results, figures, and file hashes. Use the runnable package for new comparisons.
