Canonical Sequence Maps and Research Downloads

Start with canonical protein maps: reference-to-reference and assay-to-reference comparisons. Direct cross-assay summaries are available below for research. MimicryMap calculates full sequence maps on demand.

Coverage summaries
Portable CSVs of record pairs, coverage and matched ranges, packaged together for both directions.
Protein-page index
Built from the range-enabled CSVs for fast retrieval of a protein’s matching records and sequence ribbons in either direction.
Statistical membership index
Derived from the summary CSV and its record metadata for sample and group analyses. SeroMap applies identity and coverage cutoffs, then joins set memberships to antibody measurements.

The two indexes package sequence evidence for different queries; neither contains antibody measurements or enrichment results. For SeroMap, install libraries through Workspace → Reference libraries. For offline installation, extract each ZIP into its own folder, then choose Install from folder. Membership indexes require the standard references. Coverage CSVs can be opened directly.
