Canonical Sequence Maps and Research Downloads

Start with canonical protein maps: reference-to-reference and assay-to-reference comparisons. Direct cross-assay summaries are available below for research. MimicryMap calculates full sequence maps on demand.

General-Use Summaries (.csv)
Directional CSVs of record pairs, coverage, matched ranges and unmatched target regions, with the original input FASTAs and a short README.
SeroMap Index (.sqlite)
One database for SeroMap protein-page ribbons and statistical memberships in both directions, built from the same completed comparison.

Mapping indexes contain sequence evidence; antibody measurements and enrichment results are calculated separately. Install through Workspace → Reference Libraries, or extract a ZIP and choose Install From Folder. Installation prepares local lookup indexes without repeating sequence matching. Coverage CSVs can be opened directly.
