Data Sources, Methods,
and Licenses

Download mimicry summaries and sequences for reference populations and assay libraries. Compare your own FASTAs on the MimicryMap homepage, or download the local pipeline.

Each summary CSV covers one comparison at ≥7/9, ≥8/9 and ≥9/9 core identity. Target FASTA supplies the row sequences; Comparison FASTA supplies the full comparison population. Coverage uses each sequence’s full length. Download the field and methods guide.

Summaries retain target sequences, covered and uncovered regions, and matching-parent coverage. The original atlas tables have 22 columns; new assay-to-human tables have 28, including record annotations. The field guide describes both formats. Candidate indexes contain memberships for SeroMap statistics; full positional lookup databases are separate.

Canonical sequence maps and research downloads

Start with canonical protein maps: reference-to-reference and assay-to-reference comparisons. Direct cross-assay summaries are available below as optional research downloads. MimicryMap calculates full sequence maps on demand.

Coverage summaries
CSV tables at 7/9, 8/9 and 9/9, grouped by library pair.
Protein-page index
Indexed record matches in both directions at 7/9–9/9; at least 10% coverage of either sequence. Full sequence maps remain on demand.
SeroMap candidate index
Memberships for group and sample statistics. Supported identity thresholds are shown for each download.

For SeroMap, install libraries through Workspace → Reference libraries. Offline indexes: extract each ZIP into its own folder, then choose Install from folder. Files sit at the ZIP root; the app handles installation paths. Optional candidate indexes require the standard references. Coverage CSVs can be opened directly.

References, data sources and licenses

  • Assay libraries: HuScan, full VirScan with the Exposome add-on, and HuProt 4.0 are assays run by CDI Labs. These libraries retain the assayed antigen sequences and their original identifiers.
  • Biological annotations and predicted tracks: UniProt supplies protein descriptions, genes, subcellular locations, topology, modifications and HumSAVAR variants. Gene Ontology cellular-component annotations provide a location fallback where UniProt has no classifiable location. AlphaFold supplies predicted structures and confidence scores; FreeSASA supplies structure-derived solvent accessibility, and pepsickle supplies predicted proteasomal-cleavage tracks.
