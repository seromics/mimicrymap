and Licenses

Download mimicry summaries and sequences for reference populations and assay libraries. Compare your own FASTAs on the MimicryMap homepage, or download the local pipeline.

Each comprehensive 22-column summary CSV covers one comparison at ≥7/9, ≥8/9 and ≥9/9 core identity. Target FASTA supplies the row sequences; Comparison FASTA supplies the full comparison population. Coverage uses each sequence’s full length. Download the field and methods guide.

Each summary retains the full target sequence, Shared Regions, Uncovered Residue Regions and All Matching Parent Count. Parent lists include numeric Parent|Target coverage at each identity level, rounded to one decimal after the either-side 10% listing floor. Parent sequences remain available through the comparison FASTA or database.

References, data sources and licenses

  • Assay libraries: HuScan, full VirScan with the Exposome add-on, and HuProt 4.0 are assays run by CDI Labs. These libraries retain the assayed antigen sequences and their original identifiers.
  • Biological annotations and predicted tracks: UniProt supplies protein descriptions, genes, subcellular locations, topology, modifications and HumSAVAR variants. Gene Ontology cellular-component annotations provide a location fallback where UniProt has no classifiable location. AlphaFold supplies predicted structures and confidence scores; FreeSASA supplies structure-derived solvent accessibility, and pepsickle supplies predicted proteasomal-cleavage tracks.
